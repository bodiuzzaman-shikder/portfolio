# Md. Bodiuzzaman Shikder — Portfolio Website

Personal portfolio of **Md. Bodiuzzaman Shikder**, Design Engineer (R&D) at
Adex Engineering Ltd., Bangladesh — Electrical & Mechanical Design Engineer and
R&D Researcher (power systems, robotics, mechatronics, sustainable energy).

🔗 **Live site:** https://USERNAME.github.io/portfolio/  *(update after you publish)*

## Built with
Plain HTML, CSS and JavaScript — no build step, no frameworks. Just open
`index.html` in a browser.

## Structure
```
index.html        → all content (every section)
style.css         → theme, colors, layout  (edit :root for colors)
script.js         → animations + typewriter phrases
images/           → profile photo + project images
assets/cv.pdf     → downloadable CV
HOW-TO-EDIT.md    → plain-English editing guide
```

## Updating the site
1. Edit the files (see `HOW-TO-EDIT.md`).
2. `git add .`
3. `git commit -m "Update content"`
4. `git push`

GitHub Pages redeploys automatically within a minute.
